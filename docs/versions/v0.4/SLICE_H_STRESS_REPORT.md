# Atlas of Fins｜Slice H 整合壓測報告

> 首次基線：2026-07-17
>
> 測試版本：v0.4.0-alpha.8
>
> 執行環境：隔離 Headless Chromium、390px 行動視窗與 Node.js 純系統回歸

## 測試範圍

- 依序重繪釣魚、圖鑑、漁獲、商店、居民、古海圖與船屋，共 560 次畫面切換。
- 眠潮灣與琉光群島直接停泊切換 61 次，持續重建區域事件、居民、研究與場景狀態。
- 12 次完整「出航、回到主選單、模擬離線經過、重新進入、外海等待、手動停泊」循環。
- 純系統執行 240 趟序列化航程，每 12 趟重新遷移一次 v4 存檔。
- 41 張圖鑑 SVG 重繪、三段文字大小、三段 UI 縮放及 390px 窄螢幕橫向溢位檢查。
- 一般／開發者可攜式存檔匯出、合法匯入、錯誤 JSON、模式不符、v1 舊檔與未來版本拒絕。

## 自動化入口

```bash
npm test
npm run test:browser:run
npm run test:browser:stress
```

`test:browser:stress` 會輸出本次執行的 heap、DOM、監聽器、重繪、切區與離線航程數量；任一門檻超標、存檔失效、窄螢幕溢位或瀏覽器例外都會使程序失敗。
