# Atlas of Fins｜專案文件總覽

> 最後整理：2026-07-16
> 對應程式版本：v0.3.0-alpha.4
> 用途：說明每份文件的權責、完成狀態與閱讀順序，避免歷史規格與未實作設計被誤認為目前功能。

## 1. 文件狀態定義

| 狀態 | 意義 |
|---|---|
| 現況 | 描述目前程式實際可用內容；應與程式、測試及版本號一致 |
| 已完成規格 | 對應功能已實作；保留設計背景、資料規則與驗收紀錄 |
| 核准方向 | 已由產品方向確認，但尚未開始實作 |
| 設計提案 | 為下一輪討論與估算準備；名稱、數值或順序仍可調整 |
| 歷史基準 | 保存當時的範圍與決策，不代表目前版本上限 |

發生衝突時，依序以「目前程式與自動測試 → `DEVELOPMENT_PROGRESS.md` → 對應階段規格 → 歷史基準」為準。

## 4. 已確認與仍待討論的界線

### 已確認方向

- 遊戲定位為療癒、低思考壓力、無限期可收藏的單機釣魚遊戲。
- 保留目前簡單的安全張力釣魚，不以增加操作複雜度作為主要成長。
- 長期重心為魚類圖鑑、海域、釣點、船屋、詩意航海日誌、視覺與音樂。
- 玩家會沿世界航線實際移動；船屋是可成長的移動之家。
- 世界採「真實洋流與魚類、架空港口與人物」的混合設定。
- 敘事保留少量但有記憶點的居民：燈塔守望者、魚市場老闆、生態研究員與漂流旅人。

### 尚待後續討論確認

- 第二種永久進度是否正式命名為「潮光」，以及其取得與消耗數值。
- 六個候選海域的正式名稱、順序、分支航線與每區魚種清單。
- 自動航行／離線捕獲的解鎖時點、效率與回報上限。
- 船屋成長的確切階段、家具套組數量與自由度。
- 居民姓名、外觀、個人故事與章節內容。
- v1.0 的確切魚種總量；目前以約 100 種作為產能估算，不是對外承諾。

## 5. 文件維護規則

每次開始實作前，先在設計文件將對應內容標為「已核准」，再加入 `DEVELOPMENT_PROGRESS.md` 並標記為 `[-]`。完成程式與驗證後，才可將項目改為 `[x]`、移入 `TEST_CHECKLIST.md`，並更新 README 的目前功能。

文件中的候選名稱、數值與版本順序若經討論改變，應保留決策原因或變更紀錄；不可讓「已實作」「已核准」「仍提案」三種狀態混在同一清單中。
