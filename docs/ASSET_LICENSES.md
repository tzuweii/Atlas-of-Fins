# Atlas of Fins｜素材授權紀錄

> 最後檢查：2026-07-17
> 對應版本：v0.4.0-alpha.8

## 目前使用狀態

Atlas of Fins 目前未使用任何第三方圖像、字型、音樂、音效或程式資產。

- 場景、介面、圖示與魚類輪廓皆由專案內的 HTML、CSS 與 SVG 程式化繪製。
- 音效與環境樂句由瀏覽器 Web Audio API 即時合成。
- 專案使用系統字型堆疊，未隨專案散布外部字型檔。
- 目前沒有需要放入遊戲內製作人員名單的第三方署名。
- Slice F／G 的 FishBase 連結只作為一般魚與正式觀察魚的學名、生態事實查核來源；專案未收錄其圖片或原文，遊戲內生態描述為自行撰寫的摘要。
- Slice H 只驗證既有 SVG／程式化場景的長時間重繪與記憶體基線，沒有新增生成圖片或外部素材。
- 正式魚類、地圖與場景美術仍依開發決策延後至下一個統一收尾工作包製作。

## 新增素材時的必要紀錄

未來世界海域、美術與音樂製作若加入外部或委託素材，每一項都必須在合併前記錄：

| 欄位 | 說明 |
|---|---|
| asset_name | 素材名稱 |
| asset_type | 圖像、字型、音樂、音效、程式或其他 |
| creator | 作者／權利人 |
| source_url | 原始來源，不使用無法追溯的二次上傳連結 |
| license | 完整授權名稱與版本 |
| commercial_use_allowed | 是否允許商業使用 |
| modification_allowed | 是否允許裁切、改色、衍生或重新混音 |
| attribution_required | 是否需要署名及指定格式 |
| obtained_at | 取得日期 |
| local_path | 專案內實際路徑 |
| proof_path | 授權證明、合約或頁面快照位置 |
| notes | 地區、平台、期限、再散布等限制 |

禁止提交授權不明、僅限個人使用、禁止所需修改、無法確認原作者或與預定商業發行不相容的素材。AI 輔助產生的正式資產也應記錄使用工具、生成日期、後製方式與人工審核結果。
