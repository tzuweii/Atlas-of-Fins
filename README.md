# Atlas of Fins｜鰭之圖鑑

根據《療癒釣魚養成遊戲｜初版開發規格書》製作的可玩瀏覽器遊戲，目前版本為 v0.4.0-alpha.6，已可從眠潮灣完成離線遠航、手動停泊風棲港，並在琉光群島的三個釣點認識 15 種區域魚。現有內容完整保留眠潮灣 30 種魚與三個事件，世界圖鑑目前共有 41 種不重複魚類。這是一段沒有時間壓力的海灣生活：釣魚、補完圖鑑、拜訪港口居民、販售漁獲，再把簡陋帆船慢慢整理成溫暖的家。

長期方向已正式定案為療癒單機收藏遊戲：世界地理、港口與人物完全架空，洋流關係與魚類生態參照真實資料；玩家將帶著船屋沿六大海域航行，逐步建立約 100 種魚的世界圖鑑。每日三項小目標、眠潮灣居民委託、古海圖、眠潮灣至琉光群島的離線航程、兩地釣魚與自由返航已可遊玩；正式觀察、澄野、研究航線、潮光、自動日誌及進階船屋尚未完成，完整未來規格見 [`docs/FINAL_GAME_DESIGN.md`](docs/FINAL_GAME_DESIGN.md)。正式美術圖會在玩法完成後統一設計，目前維持既有 SVG 與程式化 HTML／CSS 視覺。

## 開始遊玩

需求：Python 3（僅用來提供本機靜態伺服器）。

```bash
npm start
```

接著開啟 <http://127.0.0.1:4173>。不需要安裝 npm 套件或執行建置。

## 開發者模式

主選單選擇「開發者模式」，輸入密碼 `atlas-dev` 即可進入全解鎖測試旅程。此模式具備全部魚種圖鑑、釣點、裝備、家具、成就、測試標本與充足資源，並提供資料驅動的每日目標、居民委託、航程比例、直接停泊與區域事件控制；它使用獨立的本機主要／備份存檔，不會覆蓋一般航程。

## 已完成內容

- 按住／放開控制張力的完整釣魚小遊戲，支援滑鼠、觸控與空白鍵

- 漁獲販售、釣具／魚餌／家具商店與單一金幣經濟

- 10 件固定插槽家具與圖鑑里程碑獎勵
- 隨圖鑑進度擴建至 15 格、可放入與取回完整標本的船屋水族箱
- 13 項永久收藏成就、手動領獎、可切換稱號與水族箱拾光裝飾
- 每航海日三項無懲罰小目標，完成未領取獎勵會在換日前自動收好
- 燈塔守望者與魚市場老闆、8 個低壓委託，以及接受／放下／當面交付流程
- 分海域決定性航海日事件排程，以及眠潮灣與琉光群島各三個事件
- 多釣點、限定時段與指定天氣魚池加成，並具備分階段目標、首次稱號與重複完成獎勵
- 六步驟遊戲內教學
- 分海域程式化場景色盤、魚類 SVG、Web Audio 音效與獨立環境樂句／音樂主題
- 版本化主要／備份本機存檔及缺欄位遷移
- 眠潮灣區域、三釣點、跨區棲地與區域發現印章資料基礎
- v4 世界狀態、未知位置安全修復，以及遷移前原始存檔備份
- 共用魚類資產 resolver、正式圖片接入規格與缺圖時既有 SVG fallback
- 可由主導覽或船屋開啟的程式化古海圖，含船位、迷霧、航線預告與視角保存
- 眠潮灣至琉光群島的首次 6 分鐘／熟悉後 3 分鐘雙向航線、離線推進、外海等待與手動停泊
- 航行中的分段進度、海圖移動船位、船屋航程卡、時間異常保護與安全返航
- 風棲港、風棲淺灘、稜光珊瑚庭、暖流藍渠與星落觀察岬功能殼
- 11 種新魚的 FishBase 生態來源、合法魚池、SVG fallback、剪影、閃光、圖鑑與日誌接入
- 桌面與行動裝置響應式介面

```bash
npm test
```

目前共有 87 項單元測試，並以 `tests/fixtures/` 中的一般、高完成度與開發者三種固定 v3 存檔驗證 `currentQuests` 遷移、居民委託、世界狀態修復、航圖／航程／區域事件遷移、離線推進與一般／開發者存檔隔離。

```bash
npm run test:browser:run
```

第三方素材使用狀態記錄於 [`docs/ASSET_LICENSES.md`](docs/ASSET_LICENSES.md)，回歸驗收項目位於 [`docs/TEST_CHECKLIST.md`](docs/TEST_CHECKLIST.md)。
