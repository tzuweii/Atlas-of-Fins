# Atlas of Fins｜鰭之圖鑑

一款療癒、單機、低壓的瀏覽器收藏釣魚遊戲。玩家帶著船屋航行於架空海域，認識魚類與居民，並把主線旅程留在日誌中。

目前版本為 `v0.5.0-alpha.6`。眠潮灣、琉光群島、霧岬寒流水道、兩條雙向航線、97 種魚、觀察與研究、前三艘船屋、船別家具、永久潮光及靜潮自動釣架皆已可遊玩。

## 開始遊玩

需求：Python 3。專案不需安裝 npm 套件或建置。

```bash
npm start
```

接著開啟 <http://127.0.0.1:4173>。

此專案不使用熱更新；程式修改後請重新整理遊戲分頁。入口會使用資產修訂標記，避免瀏覽器沿用舊版介面檔案。

主選單的開發者模式密碼是 `atlas-dev`；它使用獨立存檔，不會覆蓋一般航程。

## 目前玩法

- 固定全螢幕海景是主要釣魚畫面；頁面本身不會上下或左右滑動，頂部狀態列與海景無邊框接縫；拋竿、起竿與結果確認只由右下角明確按鈕操作，海面與魚影不接受直接點擊。脫鉤逃脫只消耗本次魚餌，確認後返回海面，不會強制再拋一竿。其他功能由底部七個入口切換；進入完整功能頁時會隱藏釣魚場景，內容底色延伸至視窗底部，不會在導覽列兩側露出海景。
- 第一次一般航程會啟動不可跳過的 14 步教學；每一步都在正式遊戲畫面上顯示浮動字卡、步驟進度與唯一目標按鈕。第一尾魚會先收入漁獲箱並販售，再前往圖鑑確認紀錄仍完整保留；這次教學捕獲與販售不會推進每日、海域或居民任務。教學中的真正吞餌沒有起竿倒數，失敗可持續「再拋一竿」，教學魚餌不會消耗。
- 先依魚影、浮標、魚線、音效與驚嘆提示判斷真正吞餌，再以按住／放開控制張力；拼搏完成後進行一次獨立捕獲判定。
- 魚種出現與捕獲成功是僅有的兩類釣魚機率：每竿固定分配常見 60%、少見 30%、稀有以上 6% 與未吞餌 4%，命中層級後再依同級權重選魚；魚餌只影響出現，釣竿可影響高階出現與捕獲率，沒有拼搏品質、保底或連敗補償。
- 右上航程追蹤會分開顯示選填的特殊海況、進行中的海域主線與當日全部三項每日目標；特殊海況不影響主線。
- 97 種專屬海域魚（眠潮灣 30 種、琉光群島 33 種、霧岬 34 種）、9 個釣點、2 個正式觀察點、閃光、尺寸紀錄、熟悉度與海域圖鑑。
- 每日小目標、居民委託、選填特殊海況，以及燈塔守望者、澄野與霧禾各六節的主線故事與研究。
- 每片海域需探索至少七成魚類才完成主研究；眠潮灣為 21／30、琉光群島為 24／33、霧岬為 24／34。前兩條航線分別由守望者與澄野在章末正式交付，不會在研究達標時自動出航。
- 第二章起開放永久潮光與船隻收藏；第一章完全隱藏相關數值、商店分類與門檻。現有六艘船資料，前三艘具備購買／切換／家具／室內與共用水族箱。
- 靜潮自動釣架：只在停泊港口與遊戲完全關閉期間運作，最多結算三小時。
- 船屋內的唯讀日誌：今日潮記、稀有魚圖鑑、六個海域的主線章節，以及與主線分開的特殊海況紀錄。

## 日誌規則

- 唯一入口在「我的船屋」；其他系統不提供日誌跳轉。
- 今日潮記永遠只有當日一篇，換日即改寫，不保存歷史，也不影響進度。
- 潮記採「受公共領域海洋著作啟發、重新撰寫的原創短文」，不使用執行時生成式 AI。
- 第一次親手釣到稀有以上魚類時，解鎖該魚預先撰寫的固定相遇頁；常見與少見魚只保留圖鑑短句。
- 六個海域各是一個固定主線分類；完成預先設計的事件後才顯示對應頁面。
- 所有頁面純文字、唯讀，沒有閱讀獎勵或其他系統入口。
