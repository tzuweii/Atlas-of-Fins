# 目前魚類清單

這份文件只用來快速查看遊戲現有魚種與平衡數字，不是內容開發規則。新增、刪除或調整魚類時，必須同步更新本表。

## 機率閱讀方式

- 「未加成機率」使用初學者木竿，排除魚餌、釣竿、原生釣點、時段、天氣與事件加成：`出現率 × 捕獲成功率 = 單次拋竿成功率`。
- 每竿固定分為常見 60%、少見 30%、稀有以上 6% 與未吞餌 4%；同稀有度魚類依內部相對權重瓜分所屬預算。
- 常見與少見魚在同海域三個釣場共用；表中的地點是原生偏好。稀有以上仍由表中釣點限定。
- 現行基礎捕獲成功率為常見 90%、少見 70%、稀有 60%、史詩 50%、傳說 45%；拼搏完成後才進行一次獨立判定。
- 目前稀有級釣點每 100 竿理論期望為常見成功 54、少見成功 21、稀有成功 3.6、脫鉤 17.4、未吞餌 4；有史詩魚的霧線陸棚會把稀有以上 6% 預算分成稀有 4.92% 與史詩 1.08%，同時有史詩與首隻傳說魚的迎風白沫水道則分成稀有 4.20%、史詩 1.20% 與傳說 0.60%。
