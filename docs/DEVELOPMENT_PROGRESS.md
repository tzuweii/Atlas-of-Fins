## 7. 美術優化時機

目前美術維持可讀、風格一致與功能辨識即可，不進行大量高成本精修。建議在以下條件成立後開始集中優化：

- [ ] v0.3 核心內容已完成且不再頻繁改動版面
- [ ] 至少完成一輪外部遊玩測試
- [ ] 釣魚、圖鑑、水族箱與事件系統的資訊層級已穩定
- [ ] 已列出最需要精修的高頻畫面與資產清單

預定優化順序：

1. 魚類與閃光個體辨識度
2. 釣魚過程的水面、咬鉤與收線回饋
3. 船屋與水族箱的層次、光影與裝飾
4. 圖鑑卡片、成就圖示與介面微動效
5. 標題畫面與宣傳用視覺

## 9. 文件維護方式

每次開始新開發項目時：

1. 將項目加入對應版本並標記為 `[-]`。
2. 完成實作與測試後改為 `[x]`。
3. 更新「目前驗證狀態」與最後更新日期。
4. 在「開發紀錄」新增當日完成內容。
5. 若優先級或設計決策改變，保留原因，不只刪除舊項目。
