# MVP 驗收清單

- [ ] 可連續完成拋竿、咬餌、張力控制與捕獲
- [ ] 20 種魚皆可依釣點、時間、天氣與魚餌進入候選池
- [ ] 三支魚竿、五種魚餌可購買或裝備且效果生效
- [ ] 漁獲可個別或全部販售，價格符合稀有度與尺寸倍率
- [ ] 圖鑑支援未發現剪影、捕獲紀錄與三次捕獲資訊解鎖
- [ ] 三個釣點可切換，深水區依魚竿解鎖
- [ ] 船屋可睡覺切換時間並以固定插槽放置家具
- [ ] 十件家具可購買或由圖鑑里程碑解鎖
- [ ] 晴天、細雨與四個時段會改變視覺及魚池權重
- [ ] 每日委託會追蹤捕獲、使用魚餌、販售與大型魚條件
- [ ] 本機存檔、備份存檔、讀檔與新遊戲正常
- [ ] 桌面與窄螢幕皆可操作
