# Atlas of Fins｜鰭之圖鑑

根據《療癒釣魚養成遊戲｜初版開發規格書》製作的可玩瀏覽器遊戲，目前版本為 v0.5.0-alpha.3。v5 安全存檔、正規化事件、永久潮光與六艘船資料已完成；前三艘船可依 20／50 潮光門檻與固定金幣價格購買、在港口切換，並以 1.00／1.06／1.12 倍溫和航速鎖定每段航程。三艘已實作船另有獨立 HTML／CSS 外觀、室內、家具目錄、燈光與水族箱外框，標本收藏維持全局一致；後三艘仍只安全預告。

長期方向已正式定案為療癒單機收藏遊戲：世界地理、港口與人物完全架空，洋流關係與魚類生態參照真實資料；玩家將帶著船屋沿六大海域航行，逐步建立約 100 種魚的世界圖鑑。每日小目標、居民委託、古海圖、兩地航程、釣魚、正式觀察、澄野故事、研究、自由返航、潮光與船隻收藏骨架已可遊玩；三艘獨立室內與家具、航海日誌及自動釣架將在 v0.5 後續 Slice 完成。

## 開始遊玩

需求：Python 3（僅用來提供本機靜態伺服器）。

```bash
npm start
```

接著開啟 <http://127.0.0.1:4173>。不需要安裝 npm 套件或執行建置。

## 開發者模式

主選單選擇「開發者模式」，輸入密碼 `atlas-dev` 即可進入全解鎖測試旅程。此模式具備全部魚種圖鑑、釣點、觀察、研究、裝備、家具、成就、測試標本與充足資源，並在同一面板集中提供每日目標、居民委託、航程比例、直接停泊、區域事件、正式觀察與澄野故事控制；它使用獨立的本機主要／備份及可攜式存檔，不會覆蓋一般航程。

- 隨圖鑑進度擴建至 15 格、可放入與取回完整標本的船屋水族箱

- 分海域決定性航海日事件排程，以及眠潮灣與琉光群島各三個事件
- 多釣點、限定時段與指定天氣魚池加成，並具備分階段目標、首次稱號與重複完成獎勵

- 眠潮灣區域、三釣點、跨區棲地與區域發現印章資料基礎
- v4 世界狀態、未知位置安全修復，以及遷移前原始存檔備份
- 一般／開發者模式隔離的可攜式存檔匯出與匯入、格式驗證、舊檔遷移及匯入前備份

- 可由主導覽或船屋開啟的程式化古海圖，含船位、迷霧、航線預告與視角保存
- 眠潮灣至琉光群島的首次 6 分鐘／熟悉後 3 分鐘雙向航線、離線推進、外海等待與手動停泊
- 航行中的分段進度、海圖移動船位、船屋航程卡、時間異常保護與安全返航
- 可玩的風棲港、風棲淺灘、稜光珊瑚庭、暖流藍渠與星落觀察岬
- 11 種新魚的 FishBase 生態來源、合法魚池、SVG fallback、剪影、閃光、圖鑑與日誌接入
- 克氏雙鋸魚與雙棘甲尻魚的自動觀察、時段提示與保底，另有兩項發現前完全隱藏且不計完成度的奇景
- 澄野六段港口相遇、兩次共同觀察與手繪黑潮生態圖紀念，不受居民委託進度綁定

- 桌面與行動裝置響應式介面

## 測試

```bash
npm test
```

目前共有 98 項單元測試，並以 `tests/fixtures/` 中的一般、高完成度與開發者三種固定 v3 存檔驗證 `currentQuests` 遷移、居民委託、世界狀態修復、航圖／航程／區域事件／觀察／故事遷移、離線推進、可攜式存檔與一般／開發者模式隔離。

瀏覽器端完整流程測試位於 `tests/browser-smoke.mjs`，會驗證集中式開發者控制、港口居民、委託進度、古海圖多輸入與窄螢幕、文字／UI 縮放、可攜式存檔、首次航行、離線抵達、風棲港三釣點、兩種正式觀察與同時段保護、研究獎勵、澄野初遇、跨區魚當地印章、熟悉返航、41 種魚圖鑑、分區事件、新遊戲、張力捕獲、販售、船屋睡眠、教學完成、v3 至 v4 遷移與原始備份，以及未捕捉例外。以下指令會自行啟動本機伺服器與隔離的 Chromium，完成後清理測試程序與暫存資料：

```bash
npm run test:browser:run
```

Slice H 另提供 560 次畫面重繪、61 次切區、12 次完整離線航程與 240 趟序列化航程的壓測；量測方法與首次基線記錄於 [`docs/versions/v0.4/SLICE_H_STRESS_REPORT.md`](docs/versions/v0.4/SLICE_H_STRESS_REPORT.md)：

```bash
npm run test:browser:stress
```

第三方素材使用狀態記錄於 [`docs/ASSET_LICENSES.md`](docs/ASSET_LICENSES.md)，回歸驗收項目位於 [`docs/TEST_CHECKLIST.md`](docs/TEST_CHECKLIST.md)。
