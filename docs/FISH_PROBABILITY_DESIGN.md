# 釣魚機率設計規範（Fish Probability Design）

> 狀態：已實作並由內容驗證、單元測試與 10,000 竿／釣場蒙地卡羅驗證。
>
> 目標：不論玩家坐在哪個釣場，常見、少見與高階魚的整體命中節奏都保持穩定；
> 魚種數量只影響同稀有度內「釣到哪一隻」，不會讓某個釣場因魚種配置而特別容易空竿。

本文件記錄釣魚機率的詳細計算規格，供 `docs/GAME_DESIGN.md`、
`src/data/fish-probabilities.js` 與實際抽取邏輯對齊。所有百分比均為
**無魚餌、釣竿、時段、天氣與事件加成的每竿基準值**。

---

## 0. 核心原則（TL;DR）

1. **先固定每竿預算，再選魚。** 每竿固定分成常見 60%、少見 30%、
   高階 6%、未吞餌 4%，四者合計 100%。
2. **普通魚海域共享。** 常見、少見魚只綁定海域，在同海域三個釣場都能出現；
   原生釣場改為同級魚池內的軟性權重偏好。
3. **高階魚綁定釣場。** 稀有、史詩、傳說、神話、奇蹟仍只在指定釣場出現；
   每個釣場的高階總出現預算都固定為 6%。
4. **未來等級只瓜分高階 6%。** 新增史詩以上魚類不能提高高階總出現率，
   也不能壓低常見、少見或未吞餌預算。
5. **同級魚使用權重。** 層級命中後，再依該魚權重占同池權重總和的比例選魚，
   因此同海域、同稀有度的魚不會全部具有完全相同的成功率。
6. **魚種少可以集中。** 某釣場只有一種稀有魚時，該魚可獨占該層預算；
   多種魚則依權重瓜分。玩家遇到「任一高階魚」的節奏仍一致。
7. **失敗以脫鉤為主。** 基準未吞餌只有 4%；捕獲率差異使多數失敗發生在
   玩家完成拼搏後的脫鉤，而不是整竿完全沒有上鉤。

## 1. 名詞與海域結構

| 名詞 | 說明 |
|---|---|
| 海域 | 一個獨立釣魚地區，規劃 30～40 種專屬魚與 3 個主要釣場 |
| 釣場（spot） | 海域內的細分地點 |
| 出現（appearance） | 魚真正吞餌並可進入起竿／拼搏；之後仍可能脫鉤 |
| 捕獲（capture） | 完成拼搏後通過捕獲判定，建立漁獲與圖鑑進度 |
| 未吞餌（no bite） | 魚影試探後離開，沒有真正吞餌 |
| 海域共享池 | 常見、少見魚；同海域所有釣場共用 |
| 釣場綁定池 | 稀有以上魚；只有資料指定的釣場可選中 |
| 層級預算 | 某稀有度或高階總池在每一竿占用的固定出現百分比 |
| 魚種權重 | 魚種在同稀有度魚池內的相對份額，不是絕對出現率 |

稀有度順序：

```text
common → uncommon → rare → epic → legendary → mythic → miracle
常見     少見       稀有    史詩    傳說        神話      奇蹟
└── 海域共享池 ──┘ └──────── 釣場綁定的高階 6% ────────┘
```

## 2. 每竿基礎預算

### 2.1 頂層出現預算

| 結果池 | 每竿基礎預算 | 選魚範圍 |
|---|---:|---|
| common 常見 | 60% | 目前海域全部常見魚 |
| uncommon 少見 | 30% | 目前海域全部少見魚 |
| high-tier 稀有以上 | 6% | 目前釣場可出現的稀有以上魚 |
| no-bite 未吞餌 | 4% | 不選魚，魚影試探後離開 |
| **合計** | **100%** | |

這些是每竿的**絕對預算**，不再使用「成功漁獲中普通池占 76%、高階池占 24%」
的相對落地比例，也不再用捕獲率反推出會膨脹的高階出現率。

### 2.2 基礎捕獲率

| 稀有度 | 捕獲率 | 脫鉤率 |
|---|---:|---:|
| common | 90% | 10% |
| uncommon | 70% | 30% |
| rare | 60% | 40% |
| epic | 50% | 50% |
| legendary | 45% | 55% |
| mythic | 40% | 60% |
| miracle | 35% | 65% |

捕獲率是完成拼搏後唯一的隨機成功判定。張力表現不修改捕獲率，
也不加入保底、連敗補償、品質分數或額外逃脫判定。

---

## 3. 每一竿的判定流程

```text
每一竿
 │
 ├─[L0] 頂層預算命中
 │        common 60% / uncommon 30% / high-tier 6% / no-bite 4%
 │
 ├─[L1] 高階子層命中（只有 high-tier 需要）
 │        在當前內容開放的 rare / epic / legendary / mythic / miracle 間分配
 │
 ├─[L2] 魚種選擇
 │        依候選魚的同級權重正規化後選出一隻
 │
 └─[L3] 捕獲判定
          完成拼搏後依該稀有度捕獲率決定捕獲或脫鉤
```

L0 決定玩家這一竿的整體體感，與釣場內有幾種魚無關；L2 只決定同一層級
究竟是哪一隻魚。這能避免暖流藍渠因少見魚多、常見魚少而讓整體上鉤率下降。

---

## 4. 魚種權重與公式

### 4.1 候選魚範圍

- `common`、`uncommon`：候選魚為目前海域內該稀有度的全部魚種。
- `rare` 以上：候選魚為目前釣場內該稀有度的全部合法魚種。
- 候選魚必須至少一隻；每個釣場至少配置一種稀有以上魚，否則內容驗證失敗。

### 4.2 基礎權重

- 一般基準為 `100`。
- 常用範圍為 `80～120`。
- 同一魚池最高與最低權重原則上不得超過 `1.5` 倍。
- 只有具有明確生態、劇情或收藏定位的魚，才能以文件化例外超出常用範圍。
- 不要求每條魚的權重都唯一，但不得讓整個同級魚池全部使用相同權重。
- 新增或移除魚種時，必須重新計算並同步玩家可閱讀的未加成成功率。

目前 `FISH_APPEARANCE_WEIGHTS` 已將舊機率的相對高低遷移為以 100 為中心的
`appearanceWeight`；舊百分比已從魚種資料與抽取流程移除。

### 4.3 計算公式

設魚 `i` 屬於稀有度 `t`，位於海域 `r`、釣場 `s`：

```text
同級魚種份額 Share(i)
  = EffectiveWeight(i) / Σ EffectiveWeight(j)

魚種每竿出現率 Appearance(i)
  = TopLevelBudget(pool)
  × HighTierShare(t, s)        // common / uncommon 視為 100%
  × Share(i)

魚種每竿成功率 Success(i)
  = Appearance(i) × CaptureRate(t)
```

分母 `j` 的範圍：

- 常見、少見：同海域、同稀有度全部候選魚。
- 稀有以上：同釣場、同稀有度全部候選魚。

因此某釣場只有一隻稀有魚時，`Share(i) = 100%`；三隻魚權重不同時，
三者瓜分相同的稀有層預算，但整個釣場的稀有層總率不變。

### 4.4 權重範例

目前只有稀有魚的釣場取得完整高階 6%。假設三種稀有魚權重為
`110 / 100 / 90`：

| 魚 | 權重 | 每竿出現率 | 捕獲率 | 每竿成功率 |
|---|---:|---:|---:|---:|
| 稀有魚 A | 110 | 2.20% | 60% | 1.32% |
| 稀有魚 B | 100 | 2.00% | 60% | 1.20% |
| 稀有魚 C | 90 | 1.80% | 60% | 1.08% |
| **合計** | 300 | **6.00%** | — | **3.60%** |

若只有一種稀有魚，該魚出現率為 6%、成功率為 3.6%；這是釣場定位差異，
不是需要平均掉的異常。

## 5. 現有內容的每 100 竿基準

目前兩片海域尚未開放史詩以上，高階 6% 全部由稀有魚取得：

| 結果 | 每 100 竿 |
|---|---:|
| 常見成功 | 60 × 90% = 54.0 |
| 少見成功 | 30 × 70% = 21.0 |
| 稀有成功 | 6 × 60% = 3.6 |
| **成功合計** | **78.6** |
| 常見脫鉤 | 6.0 |
| 少見脫鉤 | 9.0 |
| 稀有脫鉤 | 2.4 |
| **脫鉤合計** | **17.4** |
| 未吞餌 | 4.0 |
| **總計** | **100.0** |

所有釣場的等級總率相同；差異只在海域共享的普通魚權重、釣場綁定的高階魚種、
高階魚數量與同級權重。脫鉤 17.4 次明顯高於未吞餌 4 次。

## 6. 未來高階 6% 的巢狀分配

新增更高稀有度時，只能重新分配高階 6%，不得增加其總額。
下表是基準開放節奏，不是每片海域必須使用完全相同的魚種數量：

| 已開放最高等級 | rare | epic | legendary | mythic | miracle | 高階成功合計／100 竿 |
|---|---:|---:|---:|---:|---:|---:|
| rare | 6.00% | — | — | — | — | 3.60 |
| epic | 4.92% | 1.08% | — | — | — | 3.49 |
| legendary | 4.20% | 1.20% | 0.60% | — | — | 3.39 |
| mythic | 3.84% | 1.20% | 0.60% | 0.36% | — | 3.32 |
| miracle | 3.60% | 1.08% | 0.60% | 0.48% | 0.24% | 3.25 |

全部等級開放時，每 100 竿的高階成功期望：

| 稀有度 | 出現預算 | 捕獲率 | 成功期望 |
|---|---:|---:|---:|
| rare | 3.60% | 60% | 2.16 |
| epic | 1.08% | 50% | 0.54 |
| legendary | 0.60% | 45% | 0.27 |
| mythic | 0.48% | 40% | 0.19 |
| miracle | 0.24% | 35% | 0.08 |
| **合計** | **6.00%** | — | **3.25** |

高階成功總量會隨更難捕獲的等級加入而由 3.6 緩慢下降至約 3.25；
減少的部分自然轉為高階脫鉤，不會增加未吞餌，也不會稀釋常見、少見魚。

## 7. 缺級遞補（Cascade）

某釣場不一定擁有目前世界已開放的每個高階等級。缺少的子層預算只在高階 6% 內遞補：

1. 缺少某等級時，優先向下一個較低且有魚的高階等級遞補。
2. 若 `rare` 也沒有魚，才向上尋找最近且有魚的高階等級。
3. 不論如何遞補，高階總出現率固定為 6%。
4. 遞補不能流入常見、少見或未吞餌，也不能讓高階總額超過 6%。
5. 若釣場完全沒有稀有以上魚，視為不合法內容，不在執行期臨時改寫預算。

範例：已開放到傳說，基準為稀有 4.20%、史詩 1.20%、傳說 0.60%；
某釣場只有稀有與傳說魚：

```text
史詩缺級 1.20% → 向下遞補給稀有

最終：稀有 5.40% + 傳說 0.60% = 高階 6.00%
```

## 8. 魚餌、釣竿、時段、天氣與事件加成

### 8.1 同級權重加成（預設）

推薦魚餌、魚餌標籤、偏好釣場、偏好時段、偏好天氣與指定魚事件，
預設乘在 `appearanceWeight` 上：

```text
EffectiveWeight(i) = BaseWeight(i) × (1 + 所有適用的相對加成)
```

效果只改變同層級抽中哪一隻，不改變常見 60%、少見 30%、高階 6%、未吞餌 4%。
這是一般加成的預設語意，也讓玩家能主動鎖定魚種而不破壞釣場整體節奏。

### 8.2 層級預算加成（限定效果）

只有明確寫著「提高稀有以上出現率」的釣竿或特殊效果，才能暫時提高高階 6%：

- 增加的高階預算等量從常見 60% 扣除。
- 少見 30% 與未吞餌 4% 預設不變。
- 所有頂層預算在加成後仍必須合計 100%。
- 高階加成只提高整個高階池，再由高階子層與魚種權重分配。
- UI 必須明示這是高階層級加成，不能以一般「較常靠近」文字混淆。

捕獲加成則直接加在當前稀有度捕獲率，最高仍限制為 98%，
且不修改任何出現預算或魚種權重。

## 9. 玩家可公告的機率

若未來向玩家公開機率，統一公布無加成基準：

```text
魚種每竿出現率 × 該稀有度捕獲率 = 魚種每竿成功率
```

公告必須以海域／釣場為上下文：

- 常見、少見魚公布該海域共享池的基礎值。
- 稀有以上魚公布合法釣場各自的基礎值。
- 若同一高階魚可在多個釣場出現，因同池競爭魚不同，應分別列出各釣場數字。
- 魚餌、釣竿、時段、天氣與事件的即時加成可維持隱藏，但不能改寫公告中的基準值。
- 新增、刪除、改權重或改釣場時，必須同步重新計算公開數字與 `FISH_CATALOG.md`。

## 10. 與程式碼的對齊

| 資料／常數 | 新角色 |
|---|---|
| `BASE_APPEARANCE_BUDGETS` | `{ common: .60, uncommon: .30, highTier: .06, noBite: .04 }` |
| `HIGH_TIER_APPEARANCE_SPLITS` | 目前內容階段或海域的高階 6% 子層分配 |
| `CAPTURE_RATE_BY_RARITY` | `{ common: .90, uncommon: .70, rare: .60, epic: .50, legendary: .45, mythic: .40, miracle: .35 }` |
| 魚種 `appearanceWeight` | 同稀有度魚池內的基礎權重，通常 80～120 |
| 魚種海域資料 | 常見、少見共享候選池；不得跨海域 |
| 魚種釣場資料 | 稀有以上的合法釣場 |
| `MAX_RARITY_FISH_PER_SPOT` | 高階魚種數量上限，不負責決定高階總率 |
| `FISH_APPEARANCE_BONUSES` | 轉為同級權重加成或明確的層級預算轉移 |

舊的每魚絕對 `baseAppearanceRate`、稀有度絕對率區間與「每釣場率總和不超過 80%」
已從現行資料、抽取、驗證與文件移除，不再是有效規則；兩套抽取規則不得同時存在。

## 附錄：完整算式範例

某釣場目前只有稀有魚，取得完整高階 6%。候選魚為：

```text
mahi       weight = 110
flyingfish weight = 100
ribbon     weight = 90
```

鬼頭刀的未加成每竿機率：

```text
Share(mahi)
  = 110 / (110 + 100 + 90)
  = 36.667%

Appearance(mahi)
  = 6% × 36.667%
  = 2.20%

Success(mahi)
  = 2.20% × 60%
  = 1.32%
```

三種魚的成功率合計仍為 `6% × 60% = 3.6%`。若加入第四種稀有魚，
只會重新分配這 6%，不會提高釣場的稀有總出現率。
